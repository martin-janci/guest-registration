# M1 — Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up a runnable Next.js 15 + Prisma + Postgres + MinIO app with password-based login, an empty admin dashboard, health endpoints, and a multi-container Docker Compose setup — the baseline on which all other milestones build.

**Architecture:** Next.js 15 App Router in standalone mode, Prisma ORM talking to Postgres 16, **custom session-cookie auth** (random 32-byte token → SHA-256 → stored as `Session.id`) backed by a `Session` table, argon2 password hashing, Tailwind + shadcn/ui for UI, MinIO reachable (but not yet used for uploads), pino JSON logging, Vitest + Testcontainers for integration tests.

> **Why no Lucia?** Lucia v3 was retired by its author in 2025 with an explicit recommendation to copy the ~80 LOC session module into your own codebase. We follow that pattern. See spec §2.

**Tech Stack:** Node 22, TypeScript 5.6 strict, Next.js 15, React 19, Prisma 5.22, `@node-rs/argon2`, Tailwind 4, shadcn/ui, Vitest 3, Testcontainers 10, pino 9, Docker Compose.

**Repo root:** the directory containing this `docs/` tree (relative paths in this plan are from that root).

```ts
import { z } from 'zod';

// Treat empty string as "absent" — .env files commonly leave optional vars set to "".
const optionalString = z
  .string()
  .optional()
  .transform((v) => (v === '' ? undefined : v));

const schema = z.object({
  DATABASE_URL: z.string().min(1),
  SESSION_COOKIE_NAME: z.string().default('guest_reg_session'),
  SESSION_COOKIE_SECURE: z
    .enum(['true', 'false'])
    .default('false')
    .transform((v) => v === 'true'),
  MINIO_ENDPOINT: z.string().url(),
  MINIO_ACCESS_KEY: z.string().min(1),
  MINIO_SECRET_KEY: z.string().min(1),
  MINIO_BUCKET: z.string().min(1),
  SMTP_HOST: z.string().min(1),
  SMTP_PORT: z
    .string()
    .transform((v) => Number.parseInt(v, 10))
    .pipe(z.number().int().positive()),
  SMTP_USER: optionalString,
  SMTP_PASSWORD: optionalString,
  SMTP_FROM: z.string().email(),
  LOG_LEVEL: z.enum(['trace', 'debug', 'info', 'warn', 'error', 'fatal']).default('info'),
});

export type Env = z.infer<typeof schema>;

export function loadEnv(source: Record<string, string | undefined> = process.env): Env {
  const parsed = schema.safeParse(source);
  if (!parsed.success) {
    throw new Error(`Invalid environment: ${parsed.error.message}`);
  }
  return parsed.data;
}

export const env: Env = /* @__PURE__ */ loadEnv();
```

## Task 6: Custom session module

**Files:**
- Create: `src/modules/auth/session.ts`
- Create: `tests/unit/session.test.ts`

Background: Lucia v3 was retired by its author with an explicit recommendation to copy the session module yourself. The implementation below is ~80 LOC and uses only the Web Crypto API + Prisma — no third-party auth dependency.

The token in the cookie is a 32-byte random value (base32-encoded). The DB stores only its SHA-256 — so a DB read can't impersonate a user. Session lifetime is 30 days; if a session is more than half-expired on validation, we slide its expiry forward by another 30 days.

- [ ] **Step 1: Write the failing test (`tests/unit/session.test.ts`)**

```ts
  it('generates 32-byte tokens encoded to a fixed length', () => {
    const a = generateSessionToken();
    const b = generateSessionToken();
    expect(a).not.toBe(b);
    expect(a.length).toBe(b.length);
    expect(a.length).toBeGreaterThanOrEqual(40); // base32 of 32 bytes

  it('hashes deterministically (sha256 hex, 64 chars)', async () => {
    const token = 'fixed-token-for-test';
    const a = await hashSessionToken(token);
```

- [ ] **Step 2: Implement `src/modules/auth/session.ts`**

```ts
import { cookies } from 'next/headers';
import { cache } from 'react';
import { prisma } from '@/db/client';
import { env } from '@/lib/env';
import type { Session, User } from '@prisma/client';

const SESSION_LIFETIME_MS = 30 * 24 * 60 * 60 * 1000; // 30 days
const SESSION_REFRESH_MS  = 15 * 24 * 60 * 60 * 1000; // refresh when ≤ 15 days remain

export type SessionValidationResult =
  | { user: User; session: Session }
  | { user: null; session: null };

// --- Token primitives ---------------------------------------------------

// 32 random bytes → base32 (no padding). 52 chars of [a-z2-7].
export function generateSessionToken(): string {
  const bytes = new Uint8Array(32);
  crypto.getRandomValues(bytes);
  return base32Encode(bytes);
}

export async function hashSessionToken(token: string): Promise<string> {
  const data = new TextEncoder().encode(token);
  const digest = await crypto.subtle.digest('SHA-256', data);
  return Array.from(new Uint8Array(digest), (b) => b.toString(16).padStart(2, '0')).join('');
}

function base32Encode(bytes: Uint8Array): string {
  const alphabet = 'abcdefghijklmnopqrstuvwxyz234567';
  let bits = 0;
  let value = 0;
  let out = '';
  for (const b of bytes) {
    value = (value << 8) | b;
    bits += 8;
    while (bits >= 5) {
      out += alphabet[(value >>> (bits - 5)) & 31];
      bits -= 5;
    }
  }
  if (bits > 0) out += alphabet[(value << (5 - bits)) & 31];
  return out;
}

// --- DB-backed session lifecycle ---------------------------------------

export async function createSession(userId: number): Promise<{ token: string; session: Session }> {
  const token = generateSessionToken();
  const sessionId = await hashSessionToken(token);
  const expiresAt = new Date(Date.now() + SESSION_LIFETIME_MS);
  const session = await prisma.session.create({
    data: { id: sessionId, userId, expiresAt },
  });
  return { token, session };
}

export async function validateSessionToken(token: string): Promise<SessionValidationResult> {
  const sessionId = await hashSessionToken(token);
  const row = await prisma.session.findUnique({
    where: { id: sessionId },
    include: { user: true },
  });
  if (!row) return { user: null, session: null };
  if (row.expiresAt.getTime() <= Date.now()) {
    await prisma.session.delete({ where: { id: sessionId } });
    return { user: null, session: null };
  }
  // Sliding expiry
  if (row.expiresAt.getTime() - Date.now() <= SESSION_REFRESH_MS) {
    const newExpiry = new Date(Date.now() + SESSION_LIFETIME_MS);
    await prisma.session.update({ where: { id: sessionId }, data: { expiresAt: newExpiry } });
    row.expiresAt = newExpiry;
  }
  const { user, ...session } = row;
  return { user, session };
}

export async function invalidateSession(sessionId: string): Promise<void> {
  await prisma.session.deleteMany({ where: { id: sessionId } });
}

// --- Cookie helpers ----------------------------------------------------

export function sessionCookieAttributes() {
  return {
    httpOnly: true,
    sameSite: 'lax' as const,
    secure: env.SESSION_COOKIE_SECURE,
    path: '/',
    maxAge: Math.floor(SESSION_LIFETIME_MS / 1000),
  };
}

// --- Per-request cached lookup (Server Components) ---------------------
```

```ts
import { prisma } from '@/db/client';
import { createSession } from './session';
import { hashPassword, verifyPassword } from './password';

export type LoginResult =
  | { ok: true; token: string; userId: number }
  | { ok: false; reason: 'invalid_credentials' };

// A dummy hash with the same argon2 parameters as production hashes.
// Computed lazily on first call — NOT at module load — so that:
//   1. `next build` does not pay the argon2 cost,
//   2. tests can configure env (logger, etc.) before the first hash runs,
//   3. cold start latency is paid by the first failed login, not module init.
let dummyHashPromise: Promise<string> | undefined;
function getDummyHash(): Promise<string> {
  dummyHashPromise ??= hashPassword('timing-equalizer');
  return dummyHashPromise;
}

export async function login(username: string, password: string): Promise<LoginResult> {
  const user = await prisma.user.findFirst({
    where: { username, deletedAt: null },
  });
  const hashToCheck = user?.passwordHash ?? (await getDummyHash());
  const passwordOk = await verifyPassword(hashToCheck, password);
  if (!user || !passwordOk) return { ok: false, reason: 'invalid_credentials' };
  const { token } = await createSession(user.id);
  return { ok: true, token, userId: user.id };
}
```

```ts
import { NextResponse, type NextRequest } from 'next/server';
import { invalidateCurrentSession } from '@/modules/auth/session';

export async function POST(req: NextRequest) {
  // CSRF defence: route handlers (unlike Server Actions) are not auto-protected.
  // Reject any cross-origin POST. SameSite=Lax already blocks the most common vector,
  // but explicit Origin/Host comparison defends against same-site attackers and old browsers.
  const origin = req.headers.get('origin');
  const host = req.headers.get('host');
  if (origin && host) {
    let originHost: string;
    try {
      originHost = new URL(origin).host;
    } catch {
      return new NextResponse('Bad Origin', { status: 400 });
    }
    if (originHost !== host) {
      return new NextResponse('Forbidden', { status: 403 });
    }
  }

  await invalidateCurrentSession();
  return NextResponse.redirect(new URL('/login', req.url), 303);
}
```

```ts
import readline from 'node:readline/promises';
import { stdin as input, stdout as output } from 'node:process';
import { prisma } from '../src/db/client.js';
import { hashPassword } from '../src/modules/auth/password.js';

// Trim only the trailing newline that readline preserves; do NOT trim user-typed
// whitespace from the password — passwords may legitimately contain spaces.
function trimEdges(s: string): string {
  return s.replace(/^\s+|\s+$/g, '');
}

// Read a password without echoing it. Sets the TTY to raw mode and reads byte-by-byte.
async function readPassword(prompt: string): Promise<string> {
  output.write(prompt);
  const wasRaw = (input as NodeJS.ReadStream).isRaw === true;
  if (input.isTTY) input.setRawMode(true);
  input.resume();
  let buf = '';
  return await new Promise<string>((resolve, reject) => {
    const onData = (chunk: Buffer) => {
      const s = chunk.toString('utf8');
      for (const ch of s) {
        const code = ch.charCodeAt(0);
        if (code === 0x03) {                             // Ctrl-C
          cleanup();
          reject(new Error('aborted'));
          return;
        }
        if (code === 0x0d || code === 0x0a) {            // Enter
          output.write('\n');
          cleanup();
          resolve(buf);
          return;
        }
        if (code === 0x7f || code === 0x08) {            // Backspace
          buf = buf.slice(0, -1);
          continue;
        }
        buf += ch;
      }
    };
    const cleanup = () => {
      input.off('data', onData);
      if (input.isTTY) input.setRawMode(wasRaw);
      input.pause();
    };
    input.on('data', onData);
  });
}

async function main(): Promise<void> {
  const rl = readline.createInterface({ input, output, terminal: true });
  let username: string;
  let email: string;
  let password: string;
  try {
    username = trimEdges(await rl.question('Username: '));
    email = trimEdges(await rl.question('Email: '));
  } finally {
    rl.close();
  }
  password = await readPassword('Password: ');
  if (!username || !email || !password) {
    console.error('All fields required');
    process.exit(1);
  }

  const user = await prisma.user.create({
    data: {
      username,
      email,
      passwordHash: await hashPassword(password),
      role: 'SUPERADMIN',
    },
  });
  console.log(`Created user ${user.id} (${user.username}) as SUPERADMIN`);
  await prisma.$disconnect();
}

main().catch((err) => {
  console.error(err);
  process.exit(1);
});
```
